# metta-pydantic

A pydantic model as a MeTTa constructor expression.

`pymetta` names no third-party library. This package is one row against the `image` point, and the seat
finds it exactly as it finds a package written by somebody else: through the
`metta.extensions` entry point, loaded at the first dispatch that has no answer
without it, or through `import metta_pydantic`, whose module body registers the same
rows.

```sh
pip install metta-pydantic          # or: pip install 'pymetta[models]'
```

Its tests are in `tests/`, and they run in the workspace suite:

```sh
sh extensions/python/test.sh ext/metta-pydantic
```
